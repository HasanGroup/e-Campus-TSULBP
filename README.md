# 🎓 e-Campus-TSULBP (ДДҲБСТ 3D Digital Twin)

Интерактивный 3D-двойник и цифровая карта кампуса **Таджикского государственного университета права, бизнеса и политики (ТГУПБП / ДДҲБСТ)** в 17-м микрорайоне города Худжанд, Таджикистан.

---

## 🌟 Основные возможности

* **Точная планировка кампуса:** Воссоздана реальная геометрия территории вдоль проспекта Ташкентский[cite: 6] на основе спутниковых данных и схемы кампуса:
  * **Главный корпус (Ректорат):** 6-этажный фасад, парадная лестница, бассейн и трёхарочные национальные ворота[cite: 2, 3, 5].
  * **Новый 5-й корпус ТГУ:** 3-этажное здание с полукруглым стеклянным входом с колоннами[cite: 4, 6].
  * **Учебные корпуса и Стадион ТГУ:** Футбольное поле с беговыми дорожками, внутренний сквер и корпуса факультетов[cite: 1, 2, 5, 6].
* **Гибридная геоданные-интеграция:** Поддержка реальных координат (`40.3125° N, 69.6225° E`), контуров зданий OpenStreetMap (Overpass API) и спутниковой подложки.
* **Интерактивная навигация:**
  * Свободное вращение, панорамирование и масштабирование камеры (`OrbitControls`).
  * Быстрые ракурсы (Общий обзор, Главные ворота и ректорат, Новый 5-й корпус, Стадион, Вид сверху).
  * Инспектор корпусов с информацией по клику.
* **Смена освещения:** Режимы «День», «Закат» и «Ночь» с архитектурной подсветкой фасадов и уличных фонарей.

---

## 🛠 Технологический стек

* **Frontend:** React, TypeScript, Vite
* **3D-графика:** Three.js (WebGL)
* **Стилизация:** Tailwind CSS
* **Геоданные:** OpenStreetMap / Overpass API & Satellite Imagery
